## Site Features

### Neo-Brutalist UI

- High-contrast layout with thick borders and hard shadows
- Custom cursor (desktop) with hover expansion
- Glitch hover effects on headings
- Infinite CSS marquees (hero ticker + portfolio highlights)
- Scroll reveal animations via `IntersectionObserver`

### Interactive & Dynamic

- **Section-aware accent colors** — HIRE ME, back-to-top, and footer link shift color as you scroll (yellow → green → purple → orange → pink → blue per section)
- **Live GitHub stats** — repos, followers, join date, activity index
- **LeetCode integration** — badges, heatmap (LeetCard), history marquee
- **Project & achievement filters** — client-side tag/year/tier filtering
- **Lazy iframe previews** — live site embeds load on scroll
- **Contact form** — opens Gmail compose with prefilled message
- **Copy to clipboard** — email and phone one-click copy
- **Mobile hamburger menu** + skip-to-content link

### Performance & Accessibility

- Compiled, minified Tailwind CSS
- Deferred JavaScript loading
- `prefers-reduced-motion` support
- Semantic HTML + JSON-LD Person schema
- Preconnect / dns-prefetch for fonts and APIs

## Quick Start

### Prerequisites

- Modern web browser
- Optional: Node.js 18+ (for Tailwind CSS build)

### Run locally

```bash
# Clone the repository
git clone https://github.com/YuvisTechPoint/Yuvraj-Portfolio.git
cd Yuvraj-Portfolio

# Serve with any static server (required for APIs & iframes)
python -m http.server 8080
# or
npx serve .
```

Open [http://localhost:8080](http://localhost:8080)

### Build Tailwind CSS (optional)

If you edit `Assets/css/input.css` or Tailwind classes:

```bash
npm install
npm run build:css    # one-time compile
npm run watch:css    # watch mode
npm run optimize:images  # compress images via sharp
```
